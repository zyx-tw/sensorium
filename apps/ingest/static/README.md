# static

`MapleMonoNFCN-Regular.woff2` and `MapleMonoNFCN-SemiBold.woff2` are the Latin
subsets of Maple Mono NF CN that every zyx.tw site serves, copied byte for byte
from `apps/ui/public/fonts/` in
[zyx1121/www.zyx.tw](https://github.com/zyx1121/www.zyx.tw)
(`packages/ui/src/fonts/README.md` there has the subset command). SIL Open Font
License 1.1, see [LICENSE.txt](LICENSE.txt). The landing page
(`src/landing.ts`) serves them under `/fonts/`. The page is English only, so it
needs no Han slices.

`favicon.ico` is the zyx mark icon from `apps/web/app/favicon.ico` in the same
repo, served at `/favicon.ico`.
